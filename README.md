## ✨ What is this?

**Little by Little** is a minimal, one-page website with a working planner built right into it. There are no accounts, no clutter and no pressure. Just a peaceful space to plan your week and celebrate your little wins.

## 🌷 Features

| | Feature | What it does |
|---|---|---|
| 📅 | **Weekly overview** | See your whole week in one place and switch between weeks |
| ✅ | **Daily to-do lists** | Add, edit, delete and tick off tasks for every day |
| 🎯 | **Weekly goals** | Write down what matters most this week |
| 🌱 | **Habit tracker** | Build healthy habits one day at a time |
| 📝 | **Notes** | Save thoughts and reminders |
| 💭 | **Weekly reflection** | Look back on what went well |
| 📊 | **Progress tracker** | Watch your progress bar fill up, and see everything you finished |
| 💾 | **Auto-save** | Your plans stay in your browser, so they're waiting for you when you return |
| 🌙 | **Dark mode** | Follows your device's light or dark setting |

## 🚀 How to use it

**Option 1: Open it online** 🌐
Visit the live demo link above.

**Option 2: Run it on your computer** 💻

1. Download or clone this repository
2. Keep all the files together in one folder
3. Double-click `index.html`

That's it! ✨ No installing, no setup.

```bash
git clone https://github.com/YOUR-USERNAME/little-by-little.git
cd little-by-little
```

## 🔒 A note on your data

Everything you write stays **only in your own browser**. There is no server and no account, so nothing is ever sent anywhere. The flip side is that your plans won't appear on a different device or browser.
